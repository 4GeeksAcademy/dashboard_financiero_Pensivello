# Banco de memoria del proyecto

Documentación de contexto para contribuidores y agentes. Los datos de producto y estado de este banco se limitan a lo comprobado en los archivos citados; no constituyen un roadmap.

## Índice

- [`product-overview.md`](product-overview.md) — qué hace la aplicación según su código actual.
- [`tech-stack.md`](tech-stack.md) — lenguajes, frameworks, infraestructura y dependencias verificadas.
- [`current-state.md`](current-state.md) — capacidades visibles, gaps observables y tareas de validación pendientes sin prioridades de producto inventadas.
- [`progress.md`](progress.md) — bitácora fechada de skills aplicadas, cambios y verificaciones ejecutadas.
- [`../specs/business-comparison.md`](../specs/business-comparison.md) — contrato/resoluciones de la especificación de comparación B2B/B2C frente a los campos reales de la API.
- [`../frontend/specs/components.md`](../frontend/specs/components.md) — responsabilidades y props actuales de los componentes React por funcionalidad.

## Criterio de evidencia

Cada hecho técnico debe citar sus archivos fuente. Cuando un comportamiento no se haya ejecutado o comprobado, se etiqueta como no verificado. No inferir funcionalidades de negocio, usuarios objetivo, objetivos comerciales ni roadmap a partir del nombre del repositorio o de dependencias instaladas.
